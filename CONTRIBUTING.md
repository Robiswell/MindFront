# Contributing

Contributions are welcome when they preserve Mindfront's privacy, evidence, and human-review boundaries.

Before submitting a change:

1. Use only synthetic examples and `example.com` addresses.
2. Do not include real workplace messages, employee names, credentials, identifiers, connector exports, vault files, or local keys.
3. Run the backend tests and Mindfront skill validation.
4. Explain any change to evidence labels, privacy boundaries, or automatic routing behavior.
5. Keep profile-derived guidance directional and never use it for employee evaluation or automatic sending.
